## 📌 Project Overview
**Tech System** is a professional management ecosystem designed to streamline interaction between students and mentors. Built with **Python/Django**, the platform focuses on bridging the gap between intelligent software management and technical education. 

This project features a high-end, modern user interface utilizing **Glassmorphism** and role-based access control to provide a seamless experience for Admins, Teachers, and Students.

> **⚠️ Project Status: Ongoing Research & Development**
> This repository contains active experiments regarding workflow automation and UI optimization.

---

## ✨ Key Features

### 🏢 Admin & Superadmin Dashboard
* **Student/Teacher Management:** Comprehensive CRUD operations for user roles.
* **Batch & Course Management:** Dynamic scheduling and course allocation.

### 👨‍🏫 Teacher Workspace
* **Batch Monitoring:** Real-time access to assigned batches.
* **Doubt Resolution:** Specialized interface to track and solve unresolved student technical doubts.
* **Resource Sharing:** Upload and manage academic resources and PDF notes.

### 👨‍💻 Student Learning Portal
* **Course Exploration:** Dynamic "Free" and "Premium" course sections.
* **Technical Doubt Module:** Post technical queries with support for screenshots and code descriptions.
* **Attendance Tracking:** Stay updated with daily attendance logs.

---

## 🎨 UI/UX Highlights
* **Glassmorphism Design:** Sophisticated `backdrop-filter` effects and semi-transparent containers.
* **Responsive Layout:** Built with a "Mobile-First" approach using CSS Grid and Flexbox.
* **Dynamic Animations:** Interactive shine-overlay buttons and hover-lift effects.
* **Role-Based Themes:** Distinct color coding (Blue for Students, Green for Teachers) for intuitive navigation.

---

## 🛠️ Tech Stack
* **Backend:** Python, Django
* **Database:** SQLite (Current Development), PostgreSQL (Production-ready)
* **Frontend:** HTML5, CSS3 (Custom Glassmorphism), JavaScript
* **Authentication:** Django Session-based Auth
